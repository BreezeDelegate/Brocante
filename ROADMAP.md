# Roadmap

## v0.1 — fondations

- capture en rafale et import multiple ;
- historique local IndexedDB et préférences persistantes ;
- Vinted et Leboncoin en file séquentielle ;
- estimation plancher / médiane ;
- Ollama optionnel ;
- API durcie, cache, Docker, CI et analyse de sécurité.

## v0.2 — fiabilité terrain

- améliorer la tolérance aux changements Vinted / Leboncoin ;
- ajouter eBay proprement ;
- reprise de file et retours d'erreur plus précis ;
- tests end-to-end sur appareils mobiles.

## v0.3 — surveillance

- favoris et seuils par objet ;
- contrôles périodiques côté serveur ;
- notifications sans dépendance payante.

## Plus tard

- identification davantage exécutée sur l'appareil ;
- meilleure fusion des comparables et score de confiance ;
- empaquetage natif Android/iOS si la PWA ne suffit plus.
